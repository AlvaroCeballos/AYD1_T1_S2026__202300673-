## 3. Actividad

## ¿Qué debe hacer?

Desarrollar una API REST que muestre su nombre junto con el nombre de su canción favorita, crear un tag de versión inicial, luego crear una rama de corrección (hotfix) para modificar la API reemplazando la canción por el nombre de un álbum, versionar este cambio con un nuevo tag y finalmente eliminar la rama hotfix.

## Pasos a realizar:

- 1. Crear la rama develop a partir de main.

- 2. Crear la rama feature/api-cancion-favorita desde develop.

- 3. Desarrollar la API REST que muestre tu nombre y tu canción favorita, y hacer commit(s) en esa rama.

- 4. Fusionar feature/api-cancion-favorita hacia develop.

- 5. Crear la rama release/1.0.0 desde develop.

- 6. Fusionar release/1.0.0 hacia main y generar el tag v1.0.0.

- 7. Crear la rama hotfix/reemplazar-cancion-por-album desde main, para corregir la API reemplazando la canción por el álbum favorito.

- 8. Fusionar el hotfix hacia main y hacia develop.


- 9. Generar el tag v1.0.1 sobre main.

10. Eliminar la rama hotfix.

## ¿Cómo debe hacerlo?

Usando Git y GitHub como repositorio remoto, con el lenguaje de programación de su elección para desarrollar la API REST.

## ¿Qué debe entregar?

Un PDF con capturas de pantalla que muestren:

- La API funcionando en ambas versiones.

- Los comandos Git utilizados o una descripción de los botones / opciones utilizadas en Visual Estudio Code.

- Los tags creados.

- Una captura donde se muestre el flujo completo de trabajo ( grafo de ramas y comits desde la extensión de Git Graph desde Visual Studio Code o imagen del panel principal de GitKraken) antes y después de eliminar la rama hotfix.

Formato de entrega: PDF con capturas de pantalla y link del repositorio público.
